# 객실·음악 리뷰 로컬 DB 참고 SQL

현재 구현은 팀의 최신 DB 마이그레이션과 통합 전인 별도 로컬 모델입니다.
팀 기존 DB에 이 SQL을 일괄 실행하지 마세요. 테이블명과 외래키를 대조한 뒤 필요한 확장만 이식해야 합니다.

## 빈 별도 DB에서 현재 화면 재현
MySQL 8.4 기준. 스키마명 preen_local_moon_erd. 이미 같은 스키마가 있으면 새 이름으로 CREATE DATABASE/USE/JDBC URL을 함께 변경하세요.
아래 순서로 1회만 실행하고 첫 오류에서 중단하세요. DDL은 일부 적용될 수 있습니다. 기존 DB 삭제·초기화 명령은 포함하지 않습니다.

02 → 03 → 04 → 08 → 09 → 10 → 11 → 12 → 14 → 15

- 02: 기반 ERD 30테이블 (신규 DB 전용)
- 03: 예시 카테고리. 팀 최신 확정 카테고리와 통합 전인 참고 데이터입니다.
- 04/09/11: 가상 숙소·객실 데이터와 시안 표시명
- 08: 객실 종류/면적·침대·시설 관련 4테이블
- 10: 오디오 테이블과 예시 데이터. 팀 적용 시 DDL/INSERT를 구분하세요.
- 12: 오디오 추천 Spotify 곡 ID 컬럼
- 14: Spotify 곡 제목/아티스트/앨범 메타데이터 테이블. API 실행에 필요합니다.
- 15: 사용자 승인 가상 이용 완료 예약·음악 리뷰4개. 실회원·실제 결제가 아닙니다.

최종36테이블, 숙소900001, 활성 객실6개, 예시 음악 리뷰4개입니다. 예시 데이터 파일은 실제 서비스 데이터로 사용하지 마세요.
DB 계정/권한은 각자 환경에 맞춰 별도로 설정합니다. 비밀번호·인증 설정과 실제 DB 데이터 파일은 포함하지 않습니다.
